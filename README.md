# Counter App

A simple Counter App built with React JS using the useState hook and onClick event handling.

## Features

- Shows a number starting from 0
- Increment (+) button increases the number by 1
- Decrement (-) button decreases the number by 1
- Reset button sets the number back to 0

## Run locally

    npm install
    npm run dev

Then open http://localhost:5173 in your browser.
